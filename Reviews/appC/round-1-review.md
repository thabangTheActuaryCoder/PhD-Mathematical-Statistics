## 4. Missing for a strong doctoral chapter

A reproducibility appendix at doctoral level lets a stranger with the stated environment regenerate every table and figure of the thesis from a single manifest, and lets an examiner without vendor access verify the parts that do not depend on vendor data while checking hashes for the parts that do. This appendix has the raw material for that (a register with licence classes, a minimum-viable-data statement, seeds, a pure-numpy reference implementation whose tests reproduce Chapter 2 to five significant figures) but not the assembly: no protocol section, no manifest, no environment pin, no description of the Chapter 3 code, and no reconciliation between that code and the chapter it serves. It also lacks the two things that would make it examinable rather than merely careful: a dated close-out plan for the 23 "to be confirmed" identifiers, and a governance statement for the sponsor data that shows an examiner can see what the reader cannot.
